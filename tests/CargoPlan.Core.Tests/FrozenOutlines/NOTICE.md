# Frozen ship silhouettes – source and license note

`ship-outlines.json` here is a frozen subset of `outlines/ship-outlines.json` as of 2026-10-26 (the entries of the
frozen test ships only), kept so pixel and placement tests don't move when the shipped outlines are rebuilt (D92, A10).

The polygons were derived automatically from top-view renders published on fleetyards.net. The renders depict Star
Citizen ships, which are the intellectual property of Cloud Imperium Rights LLC / Cloud Imperium Rights Ltd. They are
used here for a non-commercial fan project.
