- Ship list: the mouse wheel scrolls smoothly instead of jumping whole manufacturers, so no ship is skipped and the last one is fully in view.
- Ship list: every ship shows its capacity, `(64 SCU)`; a module configuration shows its own. Big numbers have a thousands comma, in the header too: `56/4,608 · 4,552 free`.
- Ship files: correcting one rack's `origin` now moves only that rack. Hologram and outline have their own place in the file (`holoOrigin`, `outlineOrigin`, `outlineScale`), so your correction no longer shifts everything else. Your own ship files keep working as they are. No picture changes.
- Ship files: a rack can lie at an angle. The new optional `rotation` turns it about its middle (`[yaw, pitch, roll]` in degrees, schema 6), and crates, drag and drop, and tool tips follow it. No shipped ship uses it yet, so no picture changes; your own files keep working, see "Turning a rack" in `docs/ship-format.md`.
- Holograms: each ship's hologram re-downloads once when first shown (about 0.3 MB per ship), since hull and racks now come from the same game model. The old hologram cache of v0.2.0 (`holo\holo-v1`, about 65 MB) is deleted once the new one is reachable; the overlay says so once.
- Ship files: the field `fleetyardsSlug` is now `modelKey`. Your own ship files with the old name keep working; a file with both is an error.
- Credits: cargo grid data and ship models from cryon.rocks (Motherlode), extracted from the Star Citizen game files. Three ships (135c, 600i Executive Edition, F7C Hornet Mk II) still use hull data from fleetyards.net. Thanks to both. Not affiliated with Motherlode, Fleetyards, ContractTracker or CIG.
