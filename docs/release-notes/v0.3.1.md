Hotkeys now work while Star Citizen is in front.

Unzip, then start `SC-CargoPlan\CargoPlan.App.exe`; Windows warns that the app is unsigned (**More info → Run anyway**). Check the download against the `.sha256` file ([how](https://github.com/MRiediger/sc-cargoplan/wiki/Installation-and-first-start#check-the-download-optional)). Run the game in **Borderless** window mode. How it works: the [wiki](https://github.com/MRiediger/sc-cargoplan/wiki).

## Fixed

- Hotkeys now fire while Star Citizen is in the foreground. Previous releases registered them with Windows, which Star Citizen does not pass through; CargoPlan now reads the keys itself.

## Changed

- Hotkeys are read only while Star Citizen or a CargoPlan window is in front, and the key also reaches the game – pick a combination Star Citizen doesn't use. Modifier (Ctrl, Alt or Win) is still required; Space is now reserved like F12. A saved `…+Space` hotkey is ignored with a notice and must be set again in Settings.

## Known issues

- If you run Star Citizen as administrator, run CargoPlan as administrator too; otherwise Windows hides key presses from CargoPlan while the game is in front.
- The [known issues of v0.3.0](https://github.com/MRiediger/sc-cargoplan/wiki/Troubleshooting#known-issues) remain unchanged.
