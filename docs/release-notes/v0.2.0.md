The plan can now keep each destination as a block of its own in a rack it shares, the way you'd stack them by hand. Nothing changes until you turn it on, except on the RAFT (see below).

Unzip, then start `SC-CargoPlan\CargoPlan.App.exe`; Windows warns that the app is unsigned (**More info → Run anyway**). Check the download against the `.sha256` file ([how](https://github.com/MRiediger/sc-cargoplan/wiki/Installation-and-first-start#check-the-download-optional)). Run the game in **Borderless** window mode. How it works: the [wiki](https://github.com/MRiediger/sc-cargoplan/wiki).

## New since v0.1.0

The editor has a **Layout** line ([what each option does](https://github.com/MRiediger/sc-cargoplan/wiki/Plan-and-editor#layout)):

- **Grouping: By destination** gives each destination a block of its own in a rack it shares, in the order of the legend.
- **Rows** chooses which way crates fill a rack, and so which way the blocks run: **Lengthwise**, bow to stern, or **Crosswise**, across the ship.
- **Section gap** leaves 1 or 2 empty rows between blocks, so you can get at the crates with the tractor beam.

The cargo comes first: blocks never make a contract wait in a Plan or a Re-plan, and they change no rack. If they don't fit, crates turn, then the gaps shrink, then the smallest destinations share a block, and a line says so.

Also: the ARGO RAFT now stacks from the top down, as in the game. Under the hood: Microsoft.Data.Sqlite 10.0.14, which reads ContractTracker's database.

## Before you update

- **No way back for your plan:** once 0.2.0 has saved it, 0.1.0 can't load it. It says so, and the file stays until you make a new plan there.
- **Sharing routes:** mission files exported from 0.2.0 don't import into 0.1.0.

## Known issues

- **With blocks and gaps:** a contract that comes in by sync moves nothing, so it can wait because the gaps split up the free room. **Re-plan** lays it in. A crate turned to keep a gap stays turned if that gap goes anyway.
- **Unsigned, no auto-update:** Windows warns at the first start of every version; check the releases for new ones.
- **Ship data are drafts:** every grid except the MISC Hull A's comes from Fleetyards and isn't checked in the game; for some racks the data name no door limit, although the game may have one.
- **The Retaliator is not included.**
- **A crate under an empty rack** in front of it can't be clicked in the ship view. Turn the view, or use its line in the legend.
- **Very large ships zoomed in all the way** (such as the Hull C): the camera can stand among the racks, and parts close to it are cut off. Zoom out a little.
- **Hologram behind a half-transparent crate:** the parts of the hologram behind it don't show; hardly visible at the default fill.
- **Ship holograms** are made from CIG's ship models and are not under MIT. They live in a release of their own, [`holo-v1`](https://github.com/MRiediger/sc-cargoplan/releases/tag/holo-v1), with its own NOTICE, not in this ZIP. The app downloads them only from there, one file per ship when you pick a hologram look, and never fetches anything from Fleetyards; **Download ship holograms** in the settings switches it off.

More, with workarounds: [Troubleshooting › Known issues](https://github.com/MRiediger/sc-cargoplan/wiki/Troubleshooting#known-issues).
