# Ship silhouettes – source and license note

The polygons in `ship-outlines.json` were derived automatically from top-view renders
published on fleetyards.net (API `api.fleetyards.net/v1/models`). The renders depict
Star Citizen ships, which are the intellectual property of Cloud Imperium Rights LLC /
Cloud Imperium Rights Ltd. They are used here for a non-commercial fan project.

These silhouette data are **not** covered by the MIT license of SC-CargoPlan.
Ship dimensions (length/beam/height) are taken from the same API.
